# UYAP Editor MCP for Antigravity

Open UDF documents in the locally installed UYAP Document Editor and export PDF on Windows x64. The independent MIT-licensed MCP uses local stdio.

Install UYAP Document Editor 5.4.20 and Java 8 x64. Extract the Windows ZIP from GitHub Releases. In Antigravity, configure the executable path from the extracted package and the local editor, Java, input and output paths.

[Source and Windows setup](https://github.com/Umutoku/uyap-editor-mcp)
